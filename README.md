# 운무암

수험생을 위한 산사 공부방. 학교와 학과를 정하면 그 이름이 모자에 새겨진 동행이 생기고, 그 뒤를 따라 암자 마당을 걷는다. 선방 방석에 앉으면 집중 시간이 시작된다.

대웅전에는 오늘의 다짐을 두고, 다실에서는 숨을 고르고, 종루의 종은 한 덩이가 끝날 때 울린다. 공부 기록은 이 브라우저에만 남는다.

## 들어가기

```bash
npm install
npm run dev
```

브라우저에서 로컬 개발 서버를 연다.

## 암자에서

- 문에서 학교와 학과를 적으면 모자 위에 새겨진다.
- **WASD** 또는 화살표로 걷는다. Shift는 천천히. 카메라는 캐릭터 뒤를 따라온다.
- 마당을 누른 채 마우스를 좌우로 끌면 시야가 돌아간다. Esc로 손을 놓는다.
- 방석 앞에서 **E**, 또는 화면에 뜬 글을 눌러 앉는다.
- 왼쪽 지도의 이름, 또는 숫자 **1–6**으로 장소를 옮긴다. 1 마당, 2 선방, 3 대웅전, 4 다실, 5 종루, 6 연못.
- 좁은 화면에서는 왼쪽 스틱으로 걷고 오른쪽을 끌어 둘러본다.
- 오른쪽 위에서 비, 소리, 새벽·낮·해질녘·밤을 고른다.

집중은 25/5, 50/10, 90/15 중에서 고른다. 기본은 50분이다.

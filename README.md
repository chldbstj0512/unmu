# 운무암

사람마다 자기 운무암이 있다. 문을 열면 내 마당이고, 다른 사람의 집과 섞이지 않는다. 같이 공부할 때는 내 선방의 빈 방석으로 부른다. 방석은 네 개라 나를 포함해 네 명까지다. 기록은 내 것이다.

문 밖에는 함께 쓰는 광장이 있다. 가운데 큰 나무 아래에 돌탑이 있고, 한국 시각으로 하루에 돌 하나를 얹는다. 얹은 날은 이 브라우저에 남는다.

목표 학교와 학과를 정하면 옆에 따라오고, 책상에 앉으면 집중 시간이 시작된다.

기록과 한 줄 목표는 책상에 남고, 다실에서는 숨을 고른다. 종은 한 덩이가 끝날 때 울린다.

## 모바일

`mobile` 브랜치는 휴대폰에서 연다. 문에서 카카오 로그인 또는 연습 입장으로 계정을 연다. 카카오 REST 키가 없으면 연습 입장이 같은 책상을 연다. 같은 브라우저는 같은 연습 계정이다.

계정에 남는 것:

- 학교, 학과, 오늘 한 줄, 오늘 목표
- 할 일
- 끝낸 집중 시간
- 과목별 이해도 (아직, 들어 봄, 풀 수 있음, 설명 가능)
- 광장에 얹은 돌의 날짜

데이터는 사람 아래에 매달린다. `users`가 계정이면 `sessions`가 로그인, `study_tasks`가 할 일, `study_logs`가 시간, `curriculum`이 이해도, `cairn_days`가 돌이다. 모의고사 코드(`exam_codes`)와 응시(`exam_attempts`), 책상 초대(`desk_guests`)는 표를 만들어 두었고 결제와 초대는 다음이다.

로컬에서는 Postgres 주소가 없으면 메모리 데이터베이스를 쓴다. 배포에서는 앱의 Postgres로 같은 표가 올라간다. 카카오 개발자 콘솔의 Redirect URI는 `{주소}/api/auth/kakao/callback` 이다.

## 들어가기

```bash
npm install
npm run dev
```

브라우저에서 로컬 개발 서버를 연다.

## 안에서

- 문에서 학교와 학과를 적으면 모자 위에 새겨진다.
- **WASD** 또는 화살표로 걷는다. 방향은 카메라가 보는 쪽이다. Shift는 천천히.
- 마당을 누른 채 마우스를 좌우로 끌면 시야가 돌아간다. Esc로 손을 놓는다.
- 방석 앞에서 **E**, 또는 화면에 뜬 글을 눌러 앉는다.
- 왼쪽 지도의 이름, 또는 숫자 **1–8**로 장소를 옮긴다. 1 마당, 2 선방, 3 대웅전, 4 다실, 5 종루, 6 연못, 7 광장, 8 시험장.
- 걸을 때 카메라는 어깨 뒤 위에 있다. 마우스를 끌면 캐릭터 주위를 돈다.
- 광장 나무 앞에서 **E**를 누르면 돌을 하나 얹는다. 하루 하나다.
- 광장 동쪽 시험장은 100석이다. **E**로 수능 모의고사를 연다. 교시, 시간과 문항 수는 수능 당일을 따른다.
- 좁은 화면에서는 왼쪽 스틱으로 걷고 오른쪽을 끌어 둘러본다.
- 하늘은 한국 시각을 따른다. 오른쪽 위에는 오늘 날짜와 시각이 뜬다. 비와 소리는 그 옆에서 고른다.

집중은 25/5, 50/10, 90/15 중에서 고른다. 기본은 50분이다.
